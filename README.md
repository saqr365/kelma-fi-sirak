# كلمة في سرك

موقع رسائل مجهولة بدون تسجيل دخول. أي زائر يكتب رسالة وتوصلك مباشرة على بريدك الإلكتروني عبر [Web3Forms](https://web3forms.com).

## المميزات

- رسائل مجهولة بالكامل، بدون حسابات.
- صندوق كتابة بحد أقصى 1000 حرف مع عداد مباشر.
- كتابة صوتية باللهجة المصرية (`ar-EG`) عبر Web Speech API.
- اقتراحات سريعة تحت الصندوق، والاقتراح الجديد يحلّ محل السابق.
- وضع نهاري وليلي: الافتراضي حسب نظام الجهاز، واختيار المستخدم يتحفظ في `localStorage`.
- واجهة عربية RTL بطابع مصري (ورق بردي وذهبي) مع أيقونات SVG.
- حماية من السبام بحقل `botcheck` مخفي.

## هيكل المشروع

```
kelma-fi-sirak/
```

## التشغيل محليًا

افتح `index.html` في أي متصفح. مفيش أي خطوة بناء أو تثبيت.

## الإعداد

مفتاح Web3Forms موجود في `index.html` داخل الحقل المخفي:

```html
<input type="hidden" name="access_key" id="accessKeyInput" value="..." />
```

لتغييره، استبدل القيمة بمفتاحك من لوحة Web3Forms. مفاتيح Web3Forms مصممة للاستخدام في كود الواجهة، ويُفضّل تقييدها بدومين موقعك من لوحة التحكم.

## النشر على GitHub Pages

1. ارفع محتوى المجلد على مستودع جديد على GitHub.
2. من **Settings → Pages**، اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقائق الموقع يظهر على `https://USERNAME.github.io/REPO/`.
